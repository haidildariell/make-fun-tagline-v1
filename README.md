# Make.fun Tagline — One Line, One Week

A one-line tagline for make.fun, generated by a small deterministic Python
program that writes the line to `/output/entry.txt`.

The tagline:

> Enter the bounty. Beat the board. Take the prize.

## How it works

Run `python3 main.py`. It joins three short fragments into one line —
"Enter the bounty. Beat the board. Take the prize." — and writes it, plus a
trailing newline, to `/output/entry.txt`. Pure Python standard library,
deterministic, no network access and no external files.
